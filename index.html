Safe Spending Rate Calculator

Solve for the initial withdrawal rate that hits a downside target
PAY-Rule-style calibration

How this works: instead of picking a spending rule and hoping it holds up, you set a downside line you're not willing to cross — e.g. "no more than a 10% chance my real portfolio falls below 15% of its starting value by year 30." This tool searches for the highest initial spending rate that respects that line, given a spending strategy, an allocation, and a set of market return assumptions. It's a standalone illustrative build, independent of and not affiliated with Retirement Researcher's PAY Rule™ tool.
